# CajaClara — paquete de lanzamiento

Este directorio contiene un producto digital listo para probar y publicar: una mini-app offline para que pequeños negocios registren ventas y gastos sin depender de una planilla compleja.

## Estructura

- `producto/`: versión entregable a compradores.
- `landing/`: página de ventas. Cambia `TU_ENLACE_KOFI` en `landing/index.html` por el enlace del producto cuando crees la tienda.
- `materiales/`: textos de publicación, mensajes y plan de venta.

## Prueba local

Abre `landing/index.html` para ver la página de venta y `producto/index.html` para usar la app.

## Oferta recomendada

- El código de la demo es público y reutilizable bajo MIT.
- El ingreso recomendado viene del servicio: personalización/instalación por US$59, con categorías, moneda, colores y una llamada de 30 minutos.
- También se puede vender un paquete preparado con guía y soporte inicial por US$19–29.
- Objetivo gradual: 3 instalaciones + 2 paquetes = aproximadamente US$215 brutos.

## Importante

La app no promete resultados financieros y no reemplaza asesoría contable. Se debe vender como herramienta de registro y visualización.
