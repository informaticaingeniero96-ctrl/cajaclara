# CajaClara

Mini-app offline para registrar ventas y gastos de un negocio pequeño. Está hecha con HTML, CSS y JavaScript sin dependencias ni servidor.

## Uso

1. Abre `index.html` en un navegador moderno.
2. Elige la moneda.
3. Registra ventas y gastos.
4. Usa CSV para compartir con tu contador o JSON para respaldar y restaurar los datos.

Los datos se guardan en `localStorage` del navegador. Si el usuario borra los datos del navegador, también se borran los movimientos; por eso se recomienda descargar un respaldo JSON regularmente.
