# Seguridad y privacidad

CajaClara guarda sus movimientos en `localStorage`. El usuario debe descargar respaldos JSON periódicos y proteger el dispositivo donde usa la aplicación.

No incluyas en issues ni pull requests:

- respaldos JSON con datos reales;
- contraseñas, tokens, claves API o credenciales;
- información identificable de clientes.

Si detectas una vulnerabilidad, abre un issue sin datos sensibles describiendo el comportamiento y una forma segura de reproducirlo.
