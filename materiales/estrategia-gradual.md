# Estrategia de ingresos gradual

La meta no depende de una sola venta ni de una plataforma. Se prueba en ciclos de 2 semanas y se conserva solo lo que genere señales reales.

## Línea A — Producto y servicio propio

- Publicar la demo gratuita y la landing.
- Contactar a 10 negocios conocidos o comunidades relevantes por semana, sin spam.
- Medir respuestas, demos y solicitudes.
- Ofrecer la personalización de US$59 solo cuando la persona ya haya visto la herramienta.

Señal de avance: 3 conversaciones de calidad por cada 10 contactos. Si no ocurre, cambiar el mensaje o el nicho, no subir la presión.

## Línea B — GitHub y open source

- Publicar el código con README claro y workflow de verificación.
- Abrir issues pequeños: categorías personalizables, importación CSV, resumen mensual.
- Aceptar feedback y mostrar un historial de mejoras.
- Solicitar GitHub Sponsors solo cuando haya contribuciones o usuarios recurrentes. Chile figura entre las regiones soportadas, pero GitHub debe aprobar el perfil y verificar los datos de pago.

Señal de avance: usuarios que abren issues, estrellas, pull requests o piden personalización.

## Línea C — Freelance técnico

Crear un perfil con tres servicios muy concretos:

1. Landing page estática rápida para negocio local — US$79.
2. Automatización de CSV/Excel y limpieza de datos — US$49.
3. Personalización de CajaClara — US$59.

Contra publicita pagos sin comisión para freelancers y permite cobrar por cuenta bancaria, tarjeta de débito, PayPal o USDC; hay que revisar la disponibilidad del método en el país antes de depender de él.

## Línea D — Recompensas por testing

Aplicar a UserTesting como complemento, no como negocio principal. La plataforma exige aprobación, micrófono y PayPal verificado; el pago depende de la demanda y suele enviarse 14 días después de completar una prueba. No usar respuestas falsas para calificar.

## Revisión quincenal

Anotar: contactos enviados, respuestas, demos, ventas, horas y dinero neto. Eliminar cualquier canal que pida pagar por adelantado o prometa rendimientos garantizados.
